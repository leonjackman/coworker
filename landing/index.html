AGENT 工作流

每一步都可观测，
每一步都在掌控中。

CoWorker 的核心是一个 LangGraph 多阶段运行时：规划、执行、校验、总结四个阶段串联成一个可打断、可恢复、可审计的工作流。

01

规划 Planner

先搜索、读取项目文件，生成明确的执行计划。写入类操作在计划批准前一律禁用。

02

执行 Executor

基于 LangChain 的 ReAct 式工具循环，在工作区受限的工具集内完成任务：搜索、读、精确替换、结构化编辑、写文件、执行命令。

03

校验 Verifier

对修改结果做二次检查，确认改动符合计划与你的意图，避免盲目收尾。

04

总结 Summarizer

把这一轮做了什么、改了哪些文件、下一步建议，整理成清晰的总结交付给你。

特性

为日常编码设计的能力集合

从数据归属到权限边界，CoWorker 把「可控」做成默认项，而不是事后补丁。

本地优先

会话、项目、审计日志、Provider 配置全部保存在本机应用数据目录，没有云账号，没有数据外传。后端跑在 127.0.0.1。

流式对话

FastAPI SSE + Electron IPC 实时流式输出，阶段状态、工具调用、最终回复边生成边呈现，随时可停止。

工作区约束

所有文件工具被限制在明确的工作区目录内，路径归一化 + 越界守卫是硬边界，不是提示词约束。

分级工具权限

  • 默认：search_files / read_file
  • 构建 + 完整访问：写入 / 替换 / 执行命令

会话与项目

独立会话 + 按项目分组的会话侧栏，模型、权限、计划状态随会话持久化，切回来接着干。

多 Provider 兼容

支持 OpenAI 兼容接口：OpenAI、Ollama /v1、自定义 Base URL。Provider 增删改、模型拉取、连通性测试都在设置面板完成。

可观测性

每次写入、替换、结构化编辑、命令执行都追加 JSONL 审计记录；Agent Trace 记录各阶段耗时与中断状态，可在设置面板回看。

主题与双语

多套主题预设 + 自定义色，亮/暗/跟随系统，半透明玻璃效果；中英界面即时切换。

安全与权限

Agent 越强，越需要看得见的边界

CoWorker 不追求「一次授权、全自动」。它把风险动作拆成可理解、可批准、可追溯的节点。

1

计划先批准，再执行

写文件、执行命令之前，Agent 必须先提交计划；批准后从同一检查点恢复执行，拒绝则带着反馈继续对话。

2

Plan / Build 双模式

Plan 模式移除所有写入类工具，只允许调研与规划；Build 模式才进入实际修改。

3

命令执行人工确认

Agent 发起命令执行会触发 human-in-the-loop 中断，进程启动前必须批准；批准记录支持按命令精确哈希去重。

4

写入即留痕

所有文件写入、精确替换、结构化编辑、命令执行都写入 JSONL 审计日志，可在设置页随时回看。

技术栈

现代、克制、可替换

CoWorker 的技术选型以「一个事实只有一个 owner」为原则：本地状态、运行时策略、Electron 进程生命周期各有归属。

◆ Electron ◆ React + TypeScript + Vite ◆ FastAPI + Pydantic ◆ LangGraph ◆ LangChain create_agent ◆ SQLite checkpoints ◆ SSE Streaming ◆ OpenAI 兼容 Provider

现在就在你的机器上跑起来
