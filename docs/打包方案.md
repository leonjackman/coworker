# Coworker 打包方案

## 一、当前项目架构

```
coworker/
├── electron/              # Electron 主进程
│   ├── main.js            # 主进程 (1062行)
│   └── preload.js         # IPC 桥接 (150行)
├── frontend/              # Vite + React 前端
│   ├── src/
│   ├── dist/              # 构建产物 (Vite 默认输出)
│   └── vite.config.ts     # 配置 base 为 './'
├── backend/               # Python FastAPI 后端
│   ├── main.py            # 后端入口
│   ├── coworker/          # 后端包 (agents, sessions, providers, etc.)
│   ├── dist/              # PyInstaller 打包产物 (在 .gitignore 中)
│   └── requirements.txt   # Python 依赖
├── assets/brand/          # 应用图标 (SVG + PNG)
├── electron-builder.config.json  # electron-builder 配置
├── package.json           # 根 package.json
└── .gitignore
```

### 关键信息

- **Electron 版本**: 43.2.0
- **前端框架**: Vite 8.2.0 + React 19.2.8 + TypeScript
- **后端**: Python FastAPI (跑在 127.0.0.1:9527)
- **通讯方式**: 渲染进程 → Electron IPC → 主进程 → HTTP 请求 → Python 后端
- **目标**: 用户安装后双击打开即用，无需额外安装

## 二、打包工具链

| 工具 | 用途 |
|------|------|
| `electron` 43.2.0 | 已有，构建 Electron 应用 |
| `electron-builder` | 跨平台打包工具，生成 .dmg / .exe |
| `pyinstaller` | 将 Python 后端打包为独立二进制 |
| `vite` | 构建前端资源到 `frontend/dist/` |

---

## 三、目录约定

| 用途 | 目录 | 说明 |
|------|------|------|
| 前端构建产物 | `frontend/dist/` | Vite 构建输出，包含 index.html + 资源文件 |
| Python 后端临时产物 | `backend/dist/` | PyInstaller 打包输出，打包前生成 |
| Electron 打包产物 | `release/` | electron-builder 输出最终安装包 |
| macOS 安装包 | `release/Coworker-1.0.0.dmg` | macOS 安装包 |
| Windows 安装包 | `release/Coworker Setup 1.0.0.exe` | Windows 安装包 |
| PyInstaller 缓存 | `.electron-builder/`, `pyinstaller_cache/` | 自动忽略 |

所有 `release/`、`*.dmg`、`*.exe`、`*.zip` 均在 `.gitignore` 中。

## 四、Python 后端集成方案

### 方案选择：PyInstaller 打包为二进制（推荐）

将 Python 后端用 PyInstaller 打包为独立可执行文件，随安装包分发。

**目录结构（打包完成后）：**

```
Coworker.app (macOS)                     Coworker.exe (Windows)
├── Contents/                            └── Resources/
│   ├── Resources/                        ├── electron/
│   │   ├── electron/                    │   ├── main.js
│   │   ├── frontend/dist/               │   ├── preload.js
│   │   └── bin/                         │   └── ...
│   │       └── backend (或 backend.exe) │   ├── frontend/dist/
│   └── MacOS/                           │   └── bin/
│       └── coworker                     │       └── backend
└── ...                                  └── ...
```

**main.js 中启动方式：**

```js
// 打包模式下启动 Python 后端
if (app.isPackaged) {
  const backendName = process.platform === 'win32' ? 'bin\\backend.exe' : 'bin/backend';
  const backendPath = path.join(process.resourcesPath, backendName);
  backendProcess = spawn(backendPath, [], { stdio: 'inherit' });
}
```

## 五、electron-builder 配置

`electron-builder.config.json` 核心配置：

```json
{
  "appId": "com.coworker.app",
  "productName": "Coworker",
  "directories": {
    "output": "release/"
  },
  "files": [
    "electron/**/*",
    "frontend/dist/**/*"
  ],
  "extraResources": [
    {
      "from": "backend/dist/backend*",
      "to": "bin/",
      "filter": ["**/*"]
    }
  ],
  "mac": {
    "target": "dmg",
    "icon": "assets/brand/cw-icon-blue-white-background.png",
    "category": "public.app-category.developer-tools"
  },
  "win": {
    "target": ["nsis"],
    "icon": "assets/brand/cw-icon-blue-white-background.png"
  },
  "linux": {
    "target": ["AppImage"],
    "icon": "assets/brand/cw-icon-blue-white-background.png"
  },
  "nsis": {
    "oneClick": false,
    "allowToChangeInstallationDirectory": true,
    "createDesktopShortcut": true,
    "createStartupShortcut": false
  }
}
```

### 配置说明

- **appId**: 应用唯一标识
- **files**: 要打包进 app.asar 的文件（electron 主进程和前端资源）
- **extraResources**: 不打包进 asar 的额外资源（Python 后端二进制）
- **mac.target**: 输出 .dmg 格式
- **win.target**: 输出 NSIS 安装包
- **linux.target**: 输出 AppImage（可选）
- **nsis**: 自定义 NSIS 安装器

## 六、打包流程

### 流程图

```
源码
  ↓
1. npm run build:frontend           → 构建 Vite 到 frontend/dist/
  ↓
2. pyinstaller 打包 Python 后端     → 生成 backend/dist/backend(.exe)
  ↓
3. electron-builder 打包            → 打包 electron + frontend/dist + bin/backend
  ↓
4. release/Coworker.dmg             ← macOS 安装包
   release/Coworker Setup.exe       ← Windows 安装包
```

### 命令

```bash
# 安装 electron-builder
npm install -D electron-builder

# 打包 Python 后端 (在当前 macOS 上)
cd backend && python -m PyInstaller --onefile --name coworker-backend main.py

# 打包
npm run build:macos    # macOS .dmg
npm run build:windows  # Windows .exe
npm run build:universal  # macOS Universal (Intel + Apple Silicon)
```

### package.json 脚本

```json
{
  "scripts": {
    "desktop": "electron .",
    "build:frontend": "npm --prefix frontend run build",
    "build:pybackend": "cd backend && python -m PyInstaller --onefile --name coworker-backend main.py",
    "build:windows": "npm run build:frontend && npm run build:pybackend && electron-builder --win",
    "build:macos": "npm run build:frontend && npm run build:pybackend && electron-builder --mac",
    "build:macos-universal": "npm run build:frontend && npm run build:pybackend && electron-builder --mac --universal",
    "build": "npm run build:frontend && npm run build:pybackend && electron-builder --mac --universal"
  }
}
```

## 七、跨平台打包注意事项

### macOS 打包

- 在 **macOS** 上运行 `npm run build:macos`
- 打包出的 .dmg 只能在 **Apple Silicon** 或对应架构运行
- 要同时支持 Intel 和 Apple Silicon，用 `--universal` 参数

### Windows 打包

- 在 **Windows** 上运行 `npm run build:windows`
- electron-builder 需要 Windows 环境
- 跨平台打包受限（Windows 打包必须在 Windows 上运行）

### Linux 打包

- 在 **Linux** 上运行 `electron-builder --linux`
- 输出 .AppImage 格式

### 解决方案：CI/CD

在 GitHub Actions 的 macOS runner 上打包 macOS 版本，在 Windows runner 上打包 Windows 版本

## 八、签名与公证（后续阶段）

### macOS 签名 + 公证

- **需要**: Apple Developer Program 会员（$99/年）
- **状态**: 会员已具备，到期时间 2027 年 2 月
- **流程**:
  1. 创建 `entitlements.plist` 声明权限（JIT、动态库等）
  2. 用 `codesign` 签名 App Bundle
  3. 用 `notarytool` 上传公证到 Apple
  4. `stapler` 打钉，使 DMG 可直接分发
- **配置**: 在 electron-builder config 中添加 `mas` 和 `afterSign` 钩子

### Windows 签名

- **需要**: 代码签名证书（如 DigiCert、Sectigo、Azure Trusted Signing）
- **价格**: ~$150-500/年
- **状态**: MVP 阶段暂不签名
- **不签名的影响**: SmartScreen 拦截提示，用户仍需手动确认

## 九、开发流程

### 开发时

```bash
# 启动 Electron (开发模式，不打包)
npm run desktop

# 构建前端 (开发时也需构建)
npm run build:frontend
```

### 打包预览

```bash
# 仅构建前端 + 打包 Python 后端不发布
npm run build:frontend
npm run build:pybackend
```

### 正式发布

```bash
# macOS 发布
npm run build:macos-universal

# Windows 发布 (需在 Windows 环境)
npm run build:windows
```
